# 什么是正常受精和异常受精?

> 更新时间：2026-09-17 (UTC+8)

正在接受试管婴儿治疗的夫妇们来院看胚胎情况时经常会听到医生说：“正常受精XX枚胚胎，异常受精XX枚胚胎。”**究竟什么是正常受精？什么又是异常受精呢？**

**什么是受精?**

受精就是精子和卵子结合形成受精卵的过程。目前试管婴儿治疗主要有两种受精方式：胚胎学家将收集到的卵子与优化处理后精子放在一起，让其自然结合，为常规体外受精(IVF)，也就是我们常说的一代试管婴儿技术；胚胎学家将单个精子在显微镜下通过显微注射针注射到卵子內，为卵胞浆内单精子显微注射（ICSI），即第二代试管婴儿技术。

授精后16-20小时左右胚胎学家会在显微镜下观察、确认卵子是否受精，观察是否有原核，有几个原核。原核的出现代表精子和卵子受精的完成。原核是在授精后6个小时后卵胞浆内才开始出现的圆形的膜状物，随着时间的延长，原核越来越明显，可见明显的核膜和核仁。

**什么是正常受精?**

正常受精是受精卵可以看到两个原核(2pronucleus, 2PN)，这两个原核一般是大小均匀，位于受精卵胞浆的中央。其中一个原核来源于“母方”，称之为“雌原核”；另外一个原核来源于“父方”，称之为“雄原核”。

**什么是异常受精？**

**无原核（0PN）：**

在观察时间内未观察到原核,通常表示精子与卵子结合失败。无原核发生的概率约为30%。其产生原因可能为：

1. 精子质量差、精子黏附和穿透机制缺陷以及透明带受体缺乏等均可引起精子穿透失败，导致卵子未受精

2. 卵子染色体数目、成熟度异常

3. 原核形成时间出现了过早或推迟

**单原核受精卵（1PN）：**

在观察时间内只见到一个原核，即单原核。1PN的发生率为3%-6%。其产生原因可能为：

1. 只有雌原核的1PN发生，精子头去凝缩障碍以及不成熟精子染色体凝缩，导致雄原核形成障碍

2. 只有雄原核的1PN发生，卵子激活障碍时，纺锤体及星状体缺陷等导致雌原核形成障碍

3. 卵母细胞的孤雌激活

4. 雌雄原核融合形成一个原核

5. 雌雄原核发育的不同步发育

**多原核受精卵（多PN）：**

受精卵内看到的原核数目多于2个原核就是多原核，最常见的是3原核(3PN)。自然状态下发生率为1%-3%，IVF过程中发生率为2%-10%。其产生原因可能为：

1. 卵母细胞不成熟或过熟；精子浓度过高；卵子透明带异常；卵泡液中高孕酮和高雄激素水平等原因导致多条精子进入卵母细胞

2. 精子进入异常卵母细胞

3. 卵母细胞内第二极体的滞留

4. 原核碎裂

**单原核、多原核及无原核都属于异常受精，由于其染色体异常率极高，常常会出现胎停、流产和胎儿遗传性疾病等，因此建议患者放弃这类胚胎。**
